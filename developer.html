Mods and shader packs

How to build your own content for FrostClient Rust

What you can make

FrostClient Rust is not a Java game, so Fabric and Forge jars do not run in it. Instead it loads two kinds of packages, and the launcher installs both on any Rust instance:

  • Content mods. Blocks, items, recipes, loot tables, tags, models, textures, sounds, languages, structures and mob effects. They are data and assets, no code, so a mod can never touch your account or your files.
  • Shader packs. WGSL shaders written against the stages of the renderer (sky, material and post passes), checked before they run and reloaded live while you edit them. Classic packs in the shaders/ .zip format work too.

File types

Every package is a zip archive. Each kind has two extensions that mean exactly the same thing, so pick whichever you like. The launcher and the game accept both.

PackageExtensionsGame folder
Content mod.hmod or .frostmodfrost-mods/
Shader pack.hshader or .frostshadershaderpacks/
Classic shader pack.zipshaderpacks/

Renaming my_mod.hmod to my_mod.frostmod is all it takes to switch; nothing inside the file changes.

Tools

You need the Rust toolchain from rustup.rs, then the two command line tools. Both run on Windows, macOS and Linux.

cargo install --git https://github.com/horizon-rust/horizon cargo-horizon-mod
cargo install --git https://github.com/horizon-rust/horizon horizon-shader-api

cargo horizon-mod creates, builds and checks content mods. horizon-shader creates, checks and packs shader packs.

Make a content mod

cargo horizon-mod new my-mod
cd my-mod
cargo horizon-mod build
cargo horizon-mod check target/horizon-mod/my_mod.hmod

new writes a working template: a manifest, one block with its model, loot table and recipe, and a language file. build packs horizon-mod.toml, assets/ and data/ into target/horizon-mod/my_mod.hmod, with the same checks the game runs. check runs the checks on a finished file.

The manifest

id = "my_mod"
name = "My Mod"
version = "0.1.0"
description = "What it adds"
authors = ["You"]
api = "0.2"
side = "both"
capabilities = ["registries"]
  • id is lowercase letters, digits and underscores, up to 64 characters. It names the mod in settings and logs.
  • side = "both" is for mods that add blocks or items. A server running the same mod checks that every player has the same version. A mod without a side line is client and never blocks a join.
  • Unknown keys are refused, so a typo shows up as an error instead of a silently ignored setting.

Adding blocks and items

A block or item is a small JSON file in data/<id>/horizon/block/ or data/<id>/horizon/item/ that copies a vanilla template and lists what differs. Models, textures and translations go in assets/<id>/ exactly as in a resource pack.

{ "template": "minecraft:iron_block",
  "properties": { "hardness": 4.0, "light": 3, "sounds": "minecraft:amethyst_block" },
  "item": true }

Make a shader pack

horizon-shader new my_pack --template post
horizon-shader check my_pack
horizon-shader pack my_pack

Templates exist for post, sky and material stages. check prints every stage with its cost, or each problem at its file, line and column. pack writes my_pack-0.1.0.hshader next to the folder.

While a pack runs in the game, saving a file checks and rebuilds it in place. If the new version has an error, the chat says where and the last good version keeps drawing.

Test it in FrostClient Rust

  • With the launcher: open your Rust instance, go to Mods or Shaders and drop the file onto the list. A new mod is switched on right away; pick a shader pack in the same tab.
  • By hand: put the mod in frost-mods/ inside the instance folder and add mod.my_mod:true to frost-mods.txt. Shader packs go in shaderpacks/.
  • In the game: Options > Mods lists every mod with what it may do and a switch. Shader packs are under Options > Video Settings > Shaders.

Mods with only assets and data switch on without a restart. Mods that add blocks, items or mob effects load when the game starts.

Share it

Send the file to your players, or post it in our Discord to have it featured. Players can install it in the launcher with one drop, whichever of the two extensions you use.

FrostClient Rust runs on Horizon, an open-source (MIT) Minecraft engine written in Rust. Its mod and shader formats are used unchanged, so packages made for Horizon work in FrostClient Rust and the other way round. The full format reference is in Horizon's documentation for mods and shader packs.
